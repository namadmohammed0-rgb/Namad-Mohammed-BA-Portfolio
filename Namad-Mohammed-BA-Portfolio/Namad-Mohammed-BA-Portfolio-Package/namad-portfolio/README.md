# Namad Mohammed BA Portfolio

A responsive portfolio for Namad Mohammed, Business Analyst and ERP Consultant.

## Included

- React portfolio website with Solarized light/dark theme toggle
- Profile-first hero section with contact links
- Selected ERP, SAP, HANA, SQL, automation, and integration projects
- Interactive What I Do and Working Toolkit cards
- Present-to-past professional experience roadmap
- Education, impact, and contact sections
- Print-ready three-page A4 portfolio PDF flow
- Standalone downloadable HTML portfolio at `Namad-Mohammed-Portfolio.html`

## Run locally

```bash
pnpm install
pnpm dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
pnpm build
```

## Portfolio files

- `client/src/pages/Home.tsx` — main portfolio page
- `client/src/index.css` — visual system, Solarized themes, responsive styling, and print rules
- `Namad-Mohammed-Portfolio.html` — standalone downloadable HTML version
